# Hi, I'm Beshoy Botros 👋

**Backend developer** building APIs and business systems with **Django**, **Django REST Framework** and **Odoo**, with React / Angular on the front end and Docker on the way to production.

- 🏗️ Currently building a **multi-tenant Odoo 17 SaaS platform** with Traefik, wildcard SSL and per-tenant provisioning
- 🤖 Recently: AI-generated consultation summaries using a **local LLM (Ollama)** running in **Celery** background jobs
- ⚡ Real-time features with **Django Channels / WebSockets** (online exam proctoring, chat)
- 🎓 Trained at **ITI** (Information Technology Institute) — full-stack & DevOps tracks
- 📍 Cairo, Egypt
